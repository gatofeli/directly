Ayuda de Directly

La forma más rápida de llegar a donde ya sabes que quieres ir.

Atajos de teclado

Nos referiremos a ellos apartir de ahora como "comandos".

Los comandos sirven para activar la extensión.

Existen 2 formas de activación: ( es decir 2 atajos de teclado / comandos )

  • "Activar la extensión": Abre la extensión en una nueva pestaña.

    Es la misma acción que haría cuando clicamos en el icono de la extensión (barra de extensiones).

  • "Activar la extensión en la misma pestaña": Abre la extensión en la pestaña actual1, ocultando temporalmente el contenido anterior a la extensión.

Atajos de teclado por defecto

Por defecto y siempre que ese comando no esté ocupado (por otra o la misma extensión) serán:

  • "Activar la extensión":

    • "Ctrl + Space": Windows y Linux
    • "Command + Space": macOS

  • "Activar la extensión en la misma pestaña":

    • "Ctrl + Shift + Space": Windows y Linux
    • "Cmd + Shift + Space": macOS

¿Puedo modificarlos?

Sí, son totalmente personalizables, bajo las condiciones del navegador2.

Para modificar un comando:

  1. Accede a las extensiones de tu navegador (desde el icono de extensiones o también Menú > "Extensiones").
  2. "Gestionar Extensiones".
  3. "Accesos directos" (parte izquierda de la pantalla).
  4. Busca la extensión de Directly y dentro de ella pulsa "editar" (icono de lápiz).
  5. Teclea tu nuevo atajo de teclado.
  • 1. Excepciones de "Activar la extensión en la misma pestaña":

    Hay ciertas pestañas (URLs) que están restringidas a las extensiones por motivos de seguridad (configuracion del navegador, nueva pestaña, ...), en estos casos la extensión siempre se abriría en una nueva pestaña.

    En el caso concreto de hacerlo desde la pagina principal de una nueva pestaña (chrome://newtab), siempre se abrirá la extensión en una nueva pestaña y luego se borraría la pestaña desde la que se llamó, simulando que se ha abierto en esa misma pestaña nueva.

  • 2. Condiciones del navegador:

    Para agregar un comando, en cualquier extensión, es obligatorio respetar las normas del navegador, resumidamente:

    • Debe tener la siguiente estructura: Primaria + "Shift" (opcional) + Secundaria.
    • Se puede añadir como tecla extra: "Shift".
    • Teclas Primarias:
      • "Alt"
      • "Ctrl" (Windows y Linux)
      • "Command" (macOs)
    • Primarias nunca pueden ir juntas:
      • NO "Ctrl" + "Alt"
      • NO "Command" + "Alt"
    • Teclas secundarias: Letras, números, barra espaciadora, flechas, teclas multimedia...
    • No se pueden usar las teclas: "Tab" ni "AltGr".
    • Los atajos de teclado son únicos, no se puede añadir el mismo comando 2 veces, aunque sea de otra extensión.

Listado de webs activas

Todas las acciones descritas en este punto se realizan desde la Coniguración de Webs.

En la configuración existen 2 listas:

  • "Webs Activas": webs a las que podrás navegar cuando se use la extensión.
    Desde este listado se podrá Eliminar/Desactivar y Modificar cada parametro de la web seleccionada.
  • "Webs Propuestas": webs que se presupone que pueden ser de utilidad para el usuario.
    Desde este listado se podrán Activar o Desactivar las webs propuestas.

Eliminar/Desactivar una web

Se podrá eliminar una web activa desde el botón con el icono de Desmarcar/Eliminar en la lista de "webs activas".
También se podra eliminar desde el listado de "webs propuestas" (si perteneciera1 a ese listado) .

Modificar una web

Solo se podrán modificar las webs que estén activas.

Pasos a seguir para modificar una web activa:

  1. Ir a la lista de "Webs activas".
  2. Busca la web que quieras editar y pulsa su botón de editar.
  3. Modifica a tu gusto.
  4. Pulsa el botón de Aceptar o Cancelar, para guardar o descartar los cambios.

Se podrá editar:

  • Título: Lo que verás cuando actives la extensión.
  • URL: Es la dirección web a la que navegaras, con los parametros de busquedas y la palabra clave2.

    Se debe de tener en cuenta que:

    • Debe contener el protocolo "http://" o "https://"
    • Debe contener como mínimo una vez la palabra clave2.
    • No pueden haber dos URL idénticas en el listado de webs activas.
    • Las modificaciones de las URL no afectan a las URL del listado "webs propuestas".

Añadir una web

Existen 2 formas (+ 1 en desarrollo) de añadir una web al listado de webs activas:

  • Activar una de las webs propuestas que SÍ te interese:

    Para ello hay que ir a la lista de Webs propuestas y desde ahí activarla pulsando el botón con el icono de añadir/favoritos.

  • Añadir una web que NO exista en la lista de "Webs propuestas" modificando la URL de una web activa:

    1. Ir a la web que te interesa añadir.

    2. Buscar en su navegador interno la palabra clave2: --DirectlyExtension--

      Asegurate de:

      1. Que no tienes filtros aplicados que luego en la busqueda no desees.
      2. Que solo has buscado "--DirectlyExtension--"
    3. Revisa la nueva URL de la página:
      • SÍ aparece "DirectlyExtension" o "--DirectlyExtension--": copia la URL completa.
      • NO aparece "DirectlyExtension" o "--DirectlyExtension--": esa web no es apta para usar con esta extensión.
    4. Ir a la lista de Webs propuestas y activar una web cualquiera de la lista.
    5. Ir a la lista de Webs activas y darle al botón de editar (de la web que acabamos de activar).
    6. Sustituir su URL con la que hemos copiado anteriormente y aceptar los cambios.

  • Añadir una web que NO exista en la lista de "Webs propuestas" desde el botón "añadir nueva url"

    Esta es una funcionalidad que está en desarrollo, por lo que aún no está disponible.

Cambiar el orden de las webs activas

En esta versión Beta no se encuentra esta funcionalidad, se añadirá más adelante.

La unica forma para re-ordenar la lista es eliminando y añadiendo las webs en el orden que interese.

  • 1. Pertenecia a "webs propuestas":

    Lo que hace que una web activada pertenezca o no a la lista de "webs propuestas" es su URL.
    No importa la modificación de su título.
    No importa si se a añadido la nueva web modificando la URL de otra web activa o propuesta.

  • 2. Palabra clave: --DirectlyExtension--

    Es lo que será sustituido por la consulta cuando se use la extensión.
    Un requisto fundamental para el manejo de la extensión.

Uso de la extensión

Para usar la extensión solo hay que seguir 3 pasos:

  1. Abrir la extensión.
  2. Escribir o no la consulta.
  3. Seleccionar la web a la que quieres navegar.

Abrir la extensión

La extensión se puede abrir de 2 formas:

  • Con los atajos de teclado.
  • Pulsando sobre el icono de la extensión, se abriría la extensión en una nueva pestaña.

Consultas

Dependiendo de si escribes o no una consulta puedes navegar dentro de una misma web a:

  • Con consulta: viajarás a la consulta, como si lo hubieras escrito directamente en su barra de búsqueda.
  • Sin consulta: viajarás a la página principal (home) de esa web.

Seleccionar la web

Despues de pulsar "Enter" o el botón de buscar, te aparecerá una lista con las webs activas.

Para navegar entre las opciones:

  • Flechas del teclado
  • Las teclas "Tab" y "Shift + Tab"
  • Ratón

Para Seleccionar la web que deseas puedes usar:

"Enter" podrá ser la tecla "Enter" o el "clic" del ratón.

  • "Enter" : para navegar en esa misma pestaña.
  • "Ctrl + Enter" : para navegar en una nueva pestaña.
  • (macOS) "Cmd + Enter" : para navegar en una nueva pestaña.

Cancelar la ejecución de la extensión

Se puede salir de la extensión de las siguientes formas:

  • Pulsando la tecla "Esc"
  • Haciendo "Clic" fuera del limete de la extensión.

Mensajes de aviso

No hay atajo de teclado seleccionado

La lista de "Webs activa" esta vacía

Error en la carga de datos

  • Problema:

    No se ha podido acceder a los datos guardados de la extensión1.

    No significa que el navegador o la extensión estén mal, simplemente ha fallado algo.

  • Causa:

    problemas de conexión, actualizaciones, espacio o saturación de procesos del navegador...

  • Solución:

    1. Espera 5 segundos y vuelve a probar.
    2. Si sigue fallando: Revisa tu conexión a internet, cierra el navegador, espera 5 segundos y vuelve a probar.
    3. Si sigue fallando: Mándanos un reporte de error.

Error al actualizar datos

  • Problema:

    No se han podido guardar los cambios en el navegador.

    No significa que el navegador o la extensión estén mal, simplemente ha fallado algo.

    Es el mismo problema que con el mensaje de error en la carga de datos.

  • Causa:

    problemas de conexión, actualizaciones, espacio o saturación de procesos del navegador...

  • Solución:

    1. Espera 5 segundos y vuelve a probar.
    2. Si sigue fallando: Revisa tu conexión a internet, cierra el navegador, espera 5 segundos y vuelve a probar.
    3. Si sigue fallando: Mándanos un reporte de error.

  • 1. Pertenecia a "webs propuestas":

    El navegador tiene reservada una pequeña base de datos local (dentro de tu ordenador) independiente para cada extensión (10 MB). La lista de "webs activas" está guardada aquí.
